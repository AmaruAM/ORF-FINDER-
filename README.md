# ORF-Scout

Extracción de ORF bacterianos y anotación comparativa de marcadores de respuesta a escasez de nutrientes en Bash.

```bash
wget https://raw.githubusercontent.com/AmaruAM/ORF-FINDER-/main/ORF_Scout.zip
unzip ORF_Scout.zip
cd ORF_Scout
bash orf_scout.sh
```

Para anotar los ORF extraídos, ejecuta `bash starvation_scout.sh` en la misma carpeta. El ZIP incluye ambos scripts, el catálogo local y sus guías. Los ensamblajes de entrada se proporcionan por separado.
